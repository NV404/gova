# Gova documentation site

Built with [fumadocs](https://fumadocs.vercel.app/).

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Build

```bash
npm run build
npm run start
```

## Content

All documentation lives under `content/docs/`. Pages are MDX; navigation is
configured by per-folder `meta.json` files.
